# 🌸 CollabHer — Skill Swap & Community Platform for Women in STEM

CollabHer is a mobile platform designed to help women in STEM **connect**, **exchange skills**, and **build communities**.  
The app makes it easy to find people who can teach or want to learn specific technical skills, join local events, and message other members directly.

---

## ✨ Features

- 🔑 **Authentication** — Secure login/sign-up with Supabase Auth.  
- 🧑 **Profiles** — Users can set skills they can teach and skills they want to learn.  
- 💬 **Skill Swap Proposals** — Propose and accept swaps directly from profile cards.  
- 📊 **Top Matches** — Intelligent skill-matching algorithm highlights your best potential partners.  
- 📝 **Posts Feed** — Create and browse posts from the community.  
- 📅 **Events** — Discover public tech events near you.  
- 🌐 **Communities** — Join interest-based groups (e.g., “AI Learners Club”, “Frontend Builders”).  
- 💌 **Messaging** — Private threads between users.  
- 🛡️ **Secure** — Row-Level Security (RLS) and policies on Supabase backend.

---

## 🛠️ Tech Stack

- **Frontend:** [React Native](https://reactnative.dev/) (Expo)  
- **Navigation:** React Navigation (Bottom Tabs + Stack)  
- **Backend:** [Supabase](https://supabase.com/) (Postgres + Auth)  
- **Database:** Postgres with RLS & SQL triggers  
- **Icons:** Expo Feather / Ionicons  
- **Styling:** Custom React Native StyleSheet
